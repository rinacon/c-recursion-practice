# c-recursion-practice
c-programing practice and tp exercises

    -This repository contains practical exercises and applications for the C programming language, organized by core programming topics.
    -Folders Structure :
    
  1/ Conditions 
It contains 5 examples of conditional sentences (if, switch).

  2/ Loops 
It contains 5 examples of conditional sentences (for, while).

  3/ Arrays 
It contains 5 examples of working with arrays.

  4/ Functions 
It contains 5 examples of building and calling functions.

  5/ voids
It contains 5 examples of building and calling voids.

    -How to Run the Code:
You can run these C programs using Code::Blocks or any C compiler. Follow the steps below:

  1. Using Code::Blocks (Recommended)
How to Open the File: Launch Code::Blocks, go to File > Open..., and select the .c file you want to run.

How to Build and Run: * Click the Build and Run icon (the yellow gear and green play button) in the toolbar.
    Key : simply press F9 on your keyboard.

Output: A terminal window will pop up showing the program's execution.

  2. Using Command Line (GCC Compiler)
If you have GCC installed, you can compile and run the code via terminal:

-Navigate to the folder containing the file.
-Compile the code:
_________________________________
Bash                             |
gcc filename.c -o output_name    |
_________________________________
-Run the program:
    1/On Windows: output_name.exe
    2/On Linux/Mac: ./output_name

"Make sure you have a C compiler (like MinGW) installed and configured within your IDE settings."
